## Secret hygiene

- Never commit API keys, tokens, private keys, or `.env` files to any repository in **GenCreator-ai**.
- All repositories enforce secret scanning before merge.

## Reporting a vulnerability

Please report suspected vulnerabilities privately via GitHub Security Advisories on the affected repository (`https://github.com/GenCreator-ai/<repo>/security/advisories/new`) rather than opening a public issue.
