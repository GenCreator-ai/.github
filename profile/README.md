# GenCreator

**Make something worth releasing.**

GenCreator develops creator tools and workflows that connect an idea, source material and editorial judgment to a finished piece of work.

Led by [Frank Riemer](https://github.com/frankxai), the work spans writing, music, video and digital products. ACOS, the Agentic Creator OS, provides reusable skills and workflow patterns within that broader practice.

## Build around a real piece of work

We welcome independent creators, creative teams and tool makers who want to test a workflow on something they intend to finish.

A useful collaboration starts with one artifact: an article, a film, a song, a lesson or a product. Define the source material, the quality bar and how the creator retains control. For a pilot, workshop or joint demonstration, write to [frank@frankx.ai](mailto:frank@frankx.ai).

## Release with care

Keep sources, rights and editorial decisions attached to the work. Check each repository for its actual release state and license. Use the canonical source for contributions when an organization copy is a mirror.
